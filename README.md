# Підготовка до уроку «Види пейзажу. Подорож у гори»

Застосунок, щоб запам’ятати конспект уроку через пригадування, а не перечитування.

- **Маршрут** — 6 етапів за підказкою «6П» (Привітання → Пригадуємо → Повідомляю тему → Пояснюю нове → Практична робота → Підсумок). Спершу кажеш уголос, потім відкриваєш і перевіряєш себе. На етапі «Пояснюю нове» є інтерактив: посунь ялинку на гору, щоб побачити загороджування.
- **Картки** — запитання за конспектом. «Ще раз» відправляє картку в кінець черги.
- **Порядок** — склади етапи уроку й кроки практичної роботи в правильній послідовності.
- **Пейзажі** — впізнай вид пейзажу за картиною з уроку.
- **Шпаргалка** — увесь урок на одній сторінці, можна надрукувати.

## Запуск

Відкрий `index.html` у браузері або увімкни GitHub Pages: **Settings → Pages → Deploy from a branch** і вибери цю гілку та папку `/ (root)`.

Зміст уроку зберігається в `data.js`.
